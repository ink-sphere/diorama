# Diorama Reader

## Scene and theme

A reader settles beside a window in afternoon light, then continues after dusk.
Default to the system's light/dark preference and retain an explicit override.

## Color

Restrained strategy. Pure white reading surface, neutral secondary surfaces,
near-black ink, and a deep olive selection accent derived from hue 110.
Dark mode uses neutral charcoal and a pale olive accent. Tokens use OKLCH.

## Typography

System sans-serif for controls; Georgia and a Unicode-capable serif fallback for
prose. Book content defaults to 20px with 1.8 line height and a 68ch measure.
Library titles use serif typography; no oversized marketing headings.

## Layout and components

A thin top bar, compact book shelf, and generous whitespace. Desktop reader has
a 280px contents panel; mobile uses a modal navigation drawer. Controls are
flat, with modest rounding and clear focus outlines. Covers come from books.

## Motion

Short state transitions only. Scrolling is immediate with reduced motion enabled.
